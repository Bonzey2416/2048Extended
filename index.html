About 2048 Extended

Version 0.9. Last updated 2025-09-29.

2048 Extended is an enhanced version of the classic 2048 game, featuring multiple game modes, grid sizes, and an AI mode.

How to play

Use the arrow keys or WASD to move the tiles. When two tiles with the same number touch, they merge into one! The goal is to create a tile with the number 2048 (or higher when using larger grid sizes). You can also enable Practice mode to allow undoing and redoing moves using Ctrl + Z and Ctrl + Y respectively.
